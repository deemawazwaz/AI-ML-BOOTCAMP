# Week 3 - Day 5

## Supervised Learning Mini Project

### Objective
Build a complete supervised learning pipeline from data preprocessing to model evaluation.

### Topics Covered
- Exploratory Data Analysis (EDA)
- Data Cleaning
- One-Hot Encoding
- Feature Scaling
- Train/Test Split
- Logistic Regression
- Random Forest
- Model Evaluation

### Libraries Used
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

### Outcome
Built an end-to-end machine learning pipeline and compared two classification models using the Titanic dataset.
