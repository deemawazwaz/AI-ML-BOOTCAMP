# Week 2 - Day 3: Linear Algebra for Machine Learning

## Objective
Learn the fundamentals of linear algebra used in machine learning, including vectors, matrices, dot products, and matrix multiplication.

## Topics Covered
- Vectors
- Matrices
- Dot Product
- Matrix Multiplication
- Shape Matching Rule

## Tasks Completed
- Represented a single data sample as a NumPy vector.
- Represented multiple data samples as a NumPy matrix.
- Computed the dot product between a feature vector and a weight vector.
- Verified the prediction using `np.dot()`.
- Used matrix multiplication (`@`) to generate predictions for all samples.
- Created a shape mismatch error intentionally.
- Explained why the error occurred and how to fix it.
