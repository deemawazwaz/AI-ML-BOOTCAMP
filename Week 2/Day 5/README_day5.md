# Week 2 - Day 5: Complete Exploratory Data Analysis (EDA)

## Objective
Perform a complete Exploratory Data Analysis (EDA) on the Titanic dataset by combining descriptive statistics, visualizations, outlier detection, bivariate analysis, and correlation analysis into a single narrated notebook.

## Topics Covered
- Descriptive Statistics
- Exploratory Data Analysis (EDA)
- Scatter Plots
- Grouped Box Plots
- Correlation Matrix
- Correlation Heatmap
- Pairplot
- Data Storytelling

## Tasks Completed
- Loaded and explored the Titanic dataset.
- Reviewed descriptive statistics.
- Created scatter plots to analyze relationships between variables.
- Created grouped box plots to compare numerical variables across categories.
- Computed the correlation matrix.
- Visualized correlations using a heatmap.
- Generated a pairplot to inspect relationships between numerical features.
- Identified the strongest correlations with the target variable.
- Summarized findings using data storytelling.

## Key Findings
- Fare showed the strongest positive correlation with survival.
- Passenger class had a negative correlation with survival.
- Family-related features (Parch and SibSp) showed weak positive correlations.
- Age showed almost no linear correlation with survival.
