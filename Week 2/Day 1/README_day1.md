# Week 2 - Day 1: Descriptive Statistics

## Objective
Learn how to compute and interpret descriptive statistics using NumPy and Pandas.

## Topics Covered
- Mean
- Median
- Mode
- Variance
- Standard Deviation
- Interquartile Range (IQR)
- Choosing the appropriate measure of central tendency

## Dataset
- tested.csv (Titanic Dataset)

## Tasks Completed
- Loaded the dataset using Pandas.
- Selected the **Age** column for analysis.
- Removed missing values.
- Calculated:
  - Mean
  - Median
  - Mode
  - Variance
  - Standard Deviation
  - Interquartile Range (IQR)
- Found the minimum and maximum age.
- Compared the mean and median to determine the better measure of a typical value.
- Documented the findings in Markdown.

## Results

| Statistic | Value |
|-----------|--------|
| Mean | 30.27 |
| Median | 27.00 |
| Mode | 21.00 |
| Variance | 201.11 |
| Standard Deviation | 14.18 |
| IQR | 18.00 |
| Minimum Age | 0.17 |
| Maximum Age | 76.00 |

## Conclusion
The Age column has a wide range of values. The median is a better measure of the typical passenger's age because it is less affected by extreme values than the mean.
