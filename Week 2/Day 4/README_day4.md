# Week 2 - Day 4: EDA Part 1 - Distributions & Outliers

## Objective
Learn the fundamentals of Exploratory Data Analysis (EDA) using statistical visualizations and outlier detection techniques.

## Topics Covered
- Exploratory Data Analysis (EDA)
- Histograms
- Box Plots
- Count Plots
- KDE Curves
- IQR Method
- Outlier Detection

## Tasks Completed
- Loaded and explored the Titanic dataset.
- Identified numeric and categorical variables.
- Created histograms for numeric columns.
- Created box plots to visualize outliers.
- Detected outliers using the IQR method.
- Created count plots for categorical variables.
- Documented observations from each visualization.
