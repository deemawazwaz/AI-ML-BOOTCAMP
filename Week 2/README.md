# Week 2 - Mathematics & Exploratory Data Analysis for Machine Learning

## Overview

This week focused on the mathematical foundations of Machine Learning and the complete Exploratory Data Analysis (EDA) workflow. The goal was to understand data before building predictive models by applying statistics, probability, linear algebra, and visualization techniques.

---

## Topics Covered

### Day 1 – Descriptive Statistics
- Mean, Median, Mode
- Variance
- Standard Deviation
- Interquartile Range (IQR)
- Percentiles & Quartiles

### Day 2 – Probability & Distributions
- Probability Basics
- Complement, Addition & Multiplication Rules
- Conditional Probability
- Bayes' Theorem
- Normal, Binomial & Uniform Distributions

### Day 3 – Linear Algebra for ML
- Vectors
- Matrices
- Dot Product
- Matrix Multiplication
- Prediction using Linear Algebra

### Day 4 – EDA Part 1
- Exploratory Data Analysis (EDA)
- Histograms
- Box Plots
- Count Plots
- KDE Plots
- Outlier Detection using IQR

### Day 5 – EDA Part 2
- Scatter Plots
- Grouped Box Plots
- Correlation Matrix
- Correlation Heatmap
- Pairplot
- Data Storytelling
- Complete EDA Notebook
